# University Study System

Offline-first personal university study organizer.

## Included
- Subjects and chapters
- Manual lecture/material entry
- Multiple attachment selection for PDF, Office files, images, audio, video, ZIP and text files
- Chapter status
- Revision queue
- Study timer
- Study-session history
- Semester/subject progress
- Local browser storage
- PWA manifest

## Important
The first version records attachment metadata rather than copying the selected file into the app database. This keeps the app lightweight and avoids silently consuming phone storage. The next version should add persistent file storage (IndexedDB) plus Backup/Restore so actual lecture files can be preserved inside the app.
